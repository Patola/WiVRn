# Steam Frame AV1 downloads

Start with the **[CI-built package setup guide](steam-frame-av1-guide.md)**.
It covers downloading a matching server and ARM64 client from
[Patola/WiVRn Releases](https://github.com/Patola/WiVRn/releases), verifying
them, installing, connecting and setting 90 Hz. Use SteamOS's stock AV1-capable
Iris driver; the old custom kernel module is retired and no longer built or
published by this branch.

For local builds, use **[Local compilation (alternative)](steam-frame-av1-building.md)**.
The complete dependency, clone and build instructions remain available there.
